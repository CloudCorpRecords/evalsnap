# Changelog

## 0.1.0 (2026-10-27)

- Initial release: `diff_snapshots` MCP tool and `diff` CLI
  command comparing a baseline and a current eval snapshot.
- Matched/added/removed cases, per-case changed status,
  score and duration deltas, regression list, improved
  count, both-scores average scores, and a pass/fail
  verdict — all deltas and averages rounded to 4 decimal
  places, with path-naming validation errors.
